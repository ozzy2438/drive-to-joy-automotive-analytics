# Phase 02 — Measurement Foundation

## Objective

Define the digital measurement contract before the demo website or data platform is built.

## Tasks

1. Define all journey events and required parameters.
2. Define dataLayer contract.
3. Define GTM variables, triggers and tags.
4. Define GA4 conversion events and custom dimensions.
5. Define UTM standards.
6. Define consent-aware measurement behaviour.
7. Define web-to-CRM matching contract.
8. Define experiment and personalisation exposure events.
9. Define QA and release validation.

## Exit criteria

- [ ] Every event has a business purpose.
- [ ] Required parameters are documented.
- [ ] No raw PII is in tracking design.
- [ ] GTM plan is documented.
- [ ] GA4 dimensions are documented.
- [ ] Consent limitations are documented.
- [ ] UTM template exists.
