# Phase 10 — Operating Model

## Objective

Show how the capability operates after launch.

## Required components

- Analytics RACI
- Tracking-change process
- GTM release process
- Reporting cadence
- Experiment governance
- Data-quality incident process
- Dashboard ownership
- CRM match-failure runbook
- Data freshness runbook
- Consent-change runbook
- Jira epics and stories
- Confluence knowledge hubs

## Exit criteria

- [ ] RACI exists.
- [ ] Runbooks exist.
- [ ] Jira backlog exists.
- [ ] Confluence structure exists.
- [ ] Change and incident processes exist.
