# Phase 06 — Dashboards

## Objective

Build stakeholder dashboards from governed analytics marts.

## Required dashboards

1. Executive Digital Performance
2. Customer Journey and UX
3. Marketing Performance
4. Data Quality Monitor
5. Experimentation Hub
6. Personalisation Performance

## Rules

- Display freshness and quality status.
- Link to metric definitions.
- Use approved marts only.
- Include a decision purpose and recommended action.
- Document limitations.

## Exit criteria

- [ ] Each dashboard has an audience and owner.
- [ ] Every metric maps to governed logic.
- [ ] Dashboard QA passes.
- [ ] Screenshots are documented.
