# Phase 03 — Demo Site

## Objective

Build a fictional automotive demo site that generates realistic automotive customer-journey events.

## Required pages

- Homepage
- Vehicle range
- Vehicle model detail
- Configurator
- Finance calculator
- Dealer locator
- Test-drive form
- Quote form
- Thank-you page
- Privacy and consent page

## Functional requirements

- Structured dataLayer events.
- Synthetic hashed lead identifier.
- Stable experiment assignment.
- Personalisation audience and holdout capability.
- Mobile-friendly journey.
- Consent state tracking.
- No real Honda branding or customer data.

## Exit criteria

- [x] Required pages work locally.
- [x] dataLayer contract is implemented.
- [x] Forms generate safe synthetic lead keys.
- [x] Experiment exposure works.
- [x] Personalisation holdout works.
- [ ] Mobile and accessibility checks are complete.

The final mobile and formal accessibility audit remains a later hardening gate;
the local responsive implementation and keyboard-accessible native controls do
not constitute audit completion.
