# Phase 09 — Personalisation

## Objective

Create measurable, consent-aware audiences and experience rules using holdout groups.

## Tasks

1. Define audience taxonomy.
2. Define eligibility and exclusions.
3. Define holdouts.
4. Define next-best actions.
5. Track exposure.
6. Measure outcomes.
7. Document privacy and fairness constraints.
8. Map concepts to Salesforce Personalisation / Marketing Cloud concepts without claiming active production access.

## Exit criteria

- [ ] Every audience has a definition.
- [ ] Every experience has an outcome metric.
- [ ] Every audience has a holdout/generic comparison.
- [ ] No sensitive targeting is used.
