# Lead Scoring Rules

See `docs/32_lead_scoring_strategy.md` for strategy. Implement rules only as an explainable analysis feature.

## Rule examples

- Add score for configurator completion, finance completion, dealer selection and repeat high-intent sessions.
- Reduce score for duplicate or invalid leads.
- Never use raw PII or sensitive attributes.
- Calibrate against CRM qualification and attendance outcomes.
- Do not automate adverse decisions using this prototype.
