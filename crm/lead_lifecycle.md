# Lead Lifecycle

```text
New → Contacted → Qualified or Disqualified → Appointment Booked
→ Attended or No Show → Ordered or Lost → Delivered where available
```

## Required status rules

| Status | Definition |
|---|---|
| New | Web lead created in CRM |
| Contacted | Sales/dealer attempted or completed contact |
| Qualified | Meets approved sales-quality rules |
| Disqualified | Duplicate, invalid, out-of-area, unavailable or low-intent according to rule |
| Appointment Booked | Test drive or consultation scheduled |
| Attended | Customer attended appointment |
| Ordered | Vehicle order confirmed |
| Lost | Opportunity did not proceed |

Status transitions and timestamps must be available for lead-quality and operational analysis.
