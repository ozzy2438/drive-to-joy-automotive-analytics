# Confluence Documentation Plan

## Purpose

This directory mirrors the recommended knowledge-management structure for a real analytics team.

## Main hubs

- Analytics Home
- Measurement Hub
- Data Quality Hub
- Dashboard Hub
- Experiment Hub
- Personalisation Hub
- Decision Log

## Documentation rules

- Every metric requires a definition.
- Every tracking change requires a specification.
- Every experiment requires pre-registration.
- Every significant data-quality incident requires a review.
- Every major decision requires a log entry.
