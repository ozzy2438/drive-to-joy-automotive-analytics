# Custom Metrics

## Derived metrics

| Metric | Formula | Notes |
|---|---|---|
| Qualified Lead Rate | Qualified leads / eligible engaged sessions | Use CRM outcome denominator rules |
| High Intent Rate | High-intent sessions / engaged sessions | High-intent event set must be versioned |
| Form Completion Rate | submits / starts | Calculate by form type and device |
| Dealer Selection Rate | dealer selects / eligible research sessions | Contextual local-intent signal |
| Configurator-to-Lead Rate | qualified leads after configurator / configurator starts | Use defined attribution window |
| CRM Match Rate | matched web leads / web lead submits | Quality metric |
| UTM Compliance Rate | valid paid sessions / paid sessions | Campaign governance metric |
| Event Completeness Rate | valid required event payloads / applicable events | Quality metric |
