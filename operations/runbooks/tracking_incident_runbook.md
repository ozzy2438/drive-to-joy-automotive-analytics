# Tracking Incident Runbook

## Trigger

Event drop, duplicate firing, missing parameter or release-related tracking issue.

## Immediate actions

1. Identify affected event, page and release version.
2. Annotate impacted reports/experiments.
3. Use GTM Preview and browser network inspection.
4. Confirm consent state behaviour.
5. Roll back GTM/site release if material and safe.

## Resolution

Validate DebugView, raw export, parameter completeness and dashboard recovery. Document root cause and prevention.
