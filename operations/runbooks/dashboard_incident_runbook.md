# Dashboard Incident Runbook

## Trigger

Dashboard is stale, broken, inconsistent or exposes invalid metric.

## Actions

1. Confirm source freshness and query status.
2. Compare dashboard output to mart query.
3. Check recent model/definition change.
4. Add visible annotation if users may act on incorrect data.
5. Restore/rollback dashboard or source model.
6. Record incident and prevention action.
