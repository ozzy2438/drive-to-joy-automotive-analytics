# Operations

## Objective

Demonstrate that the analytics capability can be operated reliably after implementation.

## Required operational capabilities

- Tracking-change process
- GTM release process
- Data-quality monitoring
- Experiment governance
- Dashboard ownership
- CRM match-failure handling
- Data freshness monitoring
- Consent-change investigation
- Reporting cadence
- Analytics RACI

## Operating principle

A dashboard is not complete merely because it renders. It needs an owner, refresh expectation, quality status, documented metric logic and a response process when data fails.
