# EPIC-01 — Measurement Foundation

## AN-101 Define Event Taxonomy

**User story:** As a Digital Analytics Specialist, I need governed event definitions so that all teams measure automotive customer behaviour consistently.

**Acceptance criteria:**

- Event names follow convention.
- Required parameters are defined.
- Web and CRM outcomes are distinguished.
- No raw PII is present.
- Experiment and personalisation context included.

## AN-102 Implement Test-Drive Tracking

**User story:** As a Digital Analytics Specialist, I need complete test-drive flow tracking so that web behaviour can join CRM lead outcomes.

**Acceptance criteria:**

- Start, error and submit events work.
- Vehicle/dealer/form context present.
- Hash key available.
- GTM Preview, DebugView and raw validation evidence attached.
