# Jira Delivery Plan

## Epics

| Epic | Objective |
|---|---|
| EPIC-01 Measurement Foundation | dataLayer, GTM, GA4, consent and UTM governance |
| EPIC-02 Data Platform | Warehouse, dbt, tests and metric marts |
| EPIC-03 Reporting | Executive, journey, marketing and quality dashboards |
| EPIC-04 Experimentation | Test workflow, analysis and decision logs |
| EPIC-05 Personalisation | Audiences, holdouts and next-best actions |
| EPIC-06 Portfolio Delivery | Repository, demo and interview materials |

## Definition of Done

A story is complete only when relevant code, documentation, QA evidence, tests, data-quality impact and rollback considerations are complete.
