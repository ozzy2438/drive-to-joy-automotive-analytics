# User Flows

## Research to test drive

```text
Landing → Vehicle Range → Model Page → Dealer Selection → Test Drive Form → Thank You
```

## Configure to lead

```text
Model Page → Configurator → Configuration Complete → Dealer Selection → Quote/Test Drive → Thank You
```

## Finance to next-best action

```text
Model Page → Finance Calculator → Result → CTA Variant → Form/Dealer/Configurator
```

## Required flow instrumentation

Each flow must include page, vehicle, dealer, form, consent and experiment context where applicable.
