# Accessibility Requirements

- Meet WCAG 2.2 AA intent where practical.
- Keyboard navigation for all form/configurator controls.
- Visible focus state.
- Semantic headings and labels.
- Form errors announced accessibly.
- Colour is not the only status signal.
- CTA text is descriptive.
- Images have meaningful alternative text.
- Motion is reduced where user preference requests it.

Accessibility issues can also create analytics bias; record major usability limitations in project notes.
