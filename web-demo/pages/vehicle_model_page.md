# Vehicle Model Page Requirements

## Purpose

Support product research and present experimentable next action.

## Required elements

- Model/variant data
- Key specifications
- Ownership/offer content
- Configurator and finance links
- Dealer/test-drive/quote path
- Experiment CTA slot

## Events

`view_vehicle_model`, `view_vehicle_variant`, `view_specification`, `view_offer`, `experiment_exposure` where active.
