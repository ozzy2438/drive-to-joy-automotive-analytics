# Experiments README

Experiments are governed product and commercial decisions, not informal design comparisons.

## Required artefacts

Every experiment requires:

1. Brief and business problem
2. Evidence and hypothesis
3. Eligibility/exclusions
4. Control and treatment description
5. Primary/secondary/guardrail metrics
6. Sample-size and duration plan
7. Tracking plan
8. QA evidence
9. Analysis plan
10. Results
11. Decision log
12. Follow-up action
