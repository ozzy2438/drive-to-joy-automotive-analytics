# EXP-FORM-002 — Mobile Form Friction

## Problem

Mobile traffic may reach forms but abandon due to field burden, validation errors, keyboard issues or unclear privacy messaging.

## Proposed treatment

Compare current form with a simplified mobile-first form flow that reduces visible fields, improves inline validation and preserves vehicle/dealer context.

## Primary metric

Form completion rate.

## Guardrails

Qualified-lead rate, duplicate lead rate, invalid lead rate, form errors and dealer routing completeness.

## Required next step

Create the same full 13-document package used for EXP-CTA-001 before launch.
