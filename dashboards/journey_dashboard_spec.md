# Journey Dashboard Specification

## Audience

Product, UX, web and digital experience teams.

## Primary decision

Which customer journey friction should be prioritised next?

## Required views

- Model page to configurator funnel
- Configurator start to completion
- Finance calculator progression
- Dealer search and selection
- Form start, error and submit funnel
- Device comparison
- Vehicle model comparison
- Returning versus new visitor behaviour
- Journey drop-off annotations

## Data sources

`fct_sessions`, `fct_vehicle_journey`, `fct_lead_funnel`.
