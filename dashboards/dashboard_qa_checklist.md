# Dashboard QA Checklist

- [ ] Dashboard has named audience and decision purpose.
- [ ] Metrics map to approved marts.
- [ ] Definitions are linked.
- [ ] Reporting period and freshness visible.
- [ ] Quality status visible.
- [ ] Filters do not create invalid aggregations.
- [ ] Totals reconcile with source query.
- [ ] Empty/error states are understandable.
- [ ] Synthetic data label is visible where applicable.
- [ ] Recommended actions are documented.
