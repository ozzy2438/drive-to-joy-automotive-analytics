# Personalisation Dashboard Specification

## Audience

CRM, MarTech and digital teams.

## Governed sources

`agg_personalisation_daily` and `agg_data_quality_daily`.

## Required views

- Audience eligibility volume
- Holdout versus personalised allocation
- Exposure rate
- Primary outcome rate
- Incremental lift
- Guardrails
- Frequency/collision indicators
- Audience version and experience version

## Rule

Always make holdout result visible beside treatment result.
