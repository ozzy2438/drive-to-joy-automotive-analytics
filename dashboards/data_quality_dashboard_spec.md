# Data Quality Dashboard Specification

## Audience

Analytics, engineering, CRM operations and digital owners.

## Required checks

- Source freshness
- Event volume anomaly
- Mandatory parameter completeness
- UTM compliance
- Duplicate lead rate
- CRM match rate
- Consent shift
- Experiment SRM
- Invalid funnel progression

## Display rules

Show severity, affected period, owner, current status, next action and issue link.
