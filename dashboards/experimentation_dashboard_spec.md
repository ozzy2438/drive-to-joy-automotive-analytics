# Experimentation Dashboard Specification

## Audience

CRO, product, analytics and leadership.

## Required views

- Experiment registry/status
- Planned versus actual sample
- Allocation and SRM status
- Primary metric by variant
- Guardrail metrics
- Segment cuts
- Quality/freshness status
- Decision recommendation
- Links to pre-registration and readout

## Rule

Do not use a dashboard colour alone to declare a winner; final decision requires documented analysis.
