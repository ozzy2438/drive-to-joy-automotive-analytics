# Data README

## Directory policy

- `external/`: source documentation only; do not blindly commit third-party data.
- `raw/`: ignored local/raw extracts.
- `interim/`: ignored transformation artefacts.
- `processed/`: ignored generated outputs.
- `synthetic/`: schema and generation specifications.
- `sample/`: tiny non-sensitive illustrative CSV samples suitable for Git.

See `DATA_DISCLOSURE.md` before adding any data.
