# Experiment Dictionary

| Field | Definition |
|---|---|
| `experiment_id` | Unique test identifier |
| `variant_id` | Control/treatment assignment |
| `primary_metric` | Pre-registered main metric |
| `collision_namespace` | Decision surface used to prevent overlap |
| `allocation_rule` | Registered deterministic assignment algorithm |
| `runtime_enabled` | Whether the instrumentation demo may activate |
| `holdout_flag` | Generic/control audience assignment for personalisation |
