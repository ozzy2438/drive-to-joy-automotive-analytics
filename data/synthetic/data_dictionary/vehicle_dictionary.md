# Vehicle Dictionary

| Field | Definition |
|---|---|
| `vehicle_model_id` | Stable fictional model key |
| `vehicle_model` | Vehicle model family |
| `model_slug` | Stable route-safe model slug |
| `variant_id` | Stable fictional variant key |
| `vehicle_variant` | Model trim/variant |
| `powertrain` | Hybrid, petrol or other approved category |
| `price_band` | Non-sensitive synthetic price range |
| `usage_segment` | Fictional usage context, not user profiling |
| `record_version` | Version of the stable reference record |
