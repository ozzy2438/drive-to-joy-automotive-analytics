# Event Dictionary

| Field/Event | Definition |
|---|---|
| `view_vehicle_model` | User viewed a vehicle model page |
| `configurator_start` | User began vehicle configuration |
| `configurator_complete` | User completed a configuration |
| `finance_calculator_complete` | User generated repayment result |
| `dealer_select` | User chose a dealer |
| `test_drive_submit` | Successful test-drive request |
| `quote_submit` | Successful quote request |
| `experiment_exposure` | User saw assigned test variant |
| `personalisation_exposure` | User saw personalised/generic experience |
