# Media Spend Schema

| Field | Type | Description |
|---|---|---|
| spend_date | DATE | Reporting date |
| channel | STRING | Paid Search/Paid Social/etc. |
| source | STRING | Platform/source |
| medium | STRING | Paid medium |
| campaign_id | STRING | Stable campaign key |
| campaign_name | STRING | Governed campaign name |
| objective | STRING | Campaign objective |
| vehicle_model | STRING | Model focus where applicable |
| spend_aud | NUMERIC | Spend in AUD |
| impressions | INTEGER | Platform impressions |
| clicks | INTEGER | Platform clicks |
