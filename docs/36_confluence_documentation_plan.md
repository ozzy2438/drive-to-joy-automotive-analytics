# Confluence Documentation Plan

## Spaces

- Analytics Home
- Measurement Hub
- Data Quality Hub
- Dashboard Hub
- Experiment Hub
- Personalisation Hub
- Decision Log

## Required pages

- Metric definitions
- Tracking specifications
- Experiment briefs and results
- Dashboard definitions
- Incident reviews
- Release notes
- Architecture decisions

## Principle

If a stakeholder cannot understand a metric, change or experiment decision without asking an engineer, the documentation is incomplete.
