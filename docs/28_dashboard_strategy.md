# Dashboard Strategy

## Decision-first principle

Dashboards must answer what happened, likely drivers, business impact, recommended action and data reliability.

## Inventory

| Dashboard | Audience | Decision |
|---|---|---|
| Executive Digital Performance | Leadership | Prioritisation and investment |
| Customer Journey and UX | Product/UX/Web | Friction resolution |
| Marketing Performance | Marketing/agencies | Channel and campaign allocation |
| Data Quality Monitor | Analytics/Engineering/CRM | Measurement remediation |
| Experimentation Hub | CRO/Product/Leadership | Ship, stop, iterate or continue |
| Personalisation Performance | CRM/MarTech/Digital | Audience and experience value |

## Required elements

- Period and freshness
- Quality status
- Definitions link
- Filter scope
- Owner
- Decision statement
- Known limitation
- Recommended action
