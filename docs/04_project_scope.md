# Project Scope

## Customer journey scope

```text
Acquisition → Landing Page → Vehicle Range → Model Page → Variant/Specs
→ Configurator / Finance Calculator / Dealer Search
→ Test Drive or Quote Form → CRM Lead → Qualified Lead
→ Appointment Booked → Appointment Attended → Vehicle Ordered
```

## In scope

- Website and marketing measurement
- Model and variant interest
- Configurator and finance journeys
- Dealer selection and lead handoff
- Test-drive and quote funnels
- CRM lead matching and qualification
- Channel/campaign quality
- Dashboards, experiments and personalisation
- Data-quality monitoring and operational documentation

## Out of scope

- Real Honda systems, data, customers or dealers
- Real transactions or inventory systems
- Raw personal data
- Production Salesforce access
- Paid-media budget execution
- Any claim of Honda performance
