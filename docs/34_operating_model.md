# Operating Model

## Cadence

| Activity | Cadence | Owner |
|---|---|---|
| Data freshness/quality check | Daily | Analytics/Data Engineering |
| Digital performance review | Weekly | Digital Analytics |
| Channel quality review | Weekly | Marketing + Analytics |
| Experiment review | Weekly | CRO/Product/Analytics |
| Dashboard definition review | Monthly | Analytics + Stakeholders |
| Measurement governance review | Monthly | Analytics + Web + CRM |
| Strategic business review | Monthly/quarterly | Leadership |

## Delivery flow

Requirement → Measurement specification → Build → QA → Release → Raw validation → Dashboard validation → Monitor → Document learning.

## Core artefacts

Use Jira for delivery work, Confluence-style documentation for knowledge, GitHub for versioned artefacts, and dashboards for decision delivery.
