# Interview Narrative

## 90-second version

Drive to Joy is a fictional, production-style automotive digital analytics and experimentation capability. It addresses the gap between website activity and commercial outcomes by connecting model research, configuration, finance evaluation, dealer selection, form conversion and CRM lead quality. The platform defines the dataLayer and GTM/GA4 measurement contract, transforms raw data in BigQuery/dbt, monitors quality, supports dashboards and provides statistically disciplined experimentation and holdout-based personalisation measurement.

## Key differentiators

- Form submit is separated from CRM-qualified lead.
- Data quality is treated as an operational capability.
- Experiment results include sample-size, SRM and guardrails.
- Personalisation is measured through holdouts.
- Every dashboard has a decision purpose.

## Limitation statement

All project-specific core data is synthetic; public sources are used only for context and schema/methodology practice.
