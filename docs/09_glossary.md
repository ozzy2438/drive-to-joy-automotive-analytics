# Glossary

| Term | Definition |
|---|---|
| Engaged Session | A session meeting the approved engagement definition in the analytical model |
| Qualified Lead | CRM-confirmed lead meeting documented sales-quality criteria |
| CPQL | Cost per Qualified Lead |
| CRM Match Rate | Share of eligible web lead submits matched to CRM outcome records |
| SRM | Sample Ratio Mismatch; unexpected variant allocation imbalance |
| Holdout | Eligible users deliberately receiving generic/control experience for incrementality measurement |
| Guardrail Metric | Metric used to prevent a local optimisation from harming customer or business outcomes |
| dataLayer | Structured client-side event and context contract consumed by GTM |
| CTA | Call to action |
| MDE | Minimum detectable effect |
| UTM | Campaign tracking parameters appended to URLs |
| Journey Stage | Approved funnel stage such as research, configure or convert |
