# Portfolio Presentation Plan

## Portfolio assets

- GitHub README and architecture
- Data disclosure and limitations
- Dashboard screenshots
- One complete experiment case study
- Executive one-pager
- Five-minute demo video
- Ten-minute technical walkthrough
- Resume bullets and cover-letter paragraph

## Reviewer path

1. Read root README.
2. Review business problem and role alignment.
3. Inspect measurement/event contract.
4. Inspect architecture and data model.
5. Review experiment case study.
6. Review dashboard definitions.
7. Review limits and ethics.

## Required honesty

Clearly label synthetic data and conceptual Salesforce mapping. Never imply access to Honda internal data or systems.
