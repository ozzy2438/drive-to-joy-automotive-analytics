# Personalisation Risks

| Risk | Mitigation |
|---|---|
| No holdout | Require control group before measurement |
| Wrong audience | Version audience logic and validate eligibility |
| Experience overload | Frequency caps and collision rules |
| Identity error | Conservative matching and uncertainty disclosure |
| Privacy issue | Consent-aware, no sensitive targeting |
| Local dealer mismatch | Dealer/context validation |
| Optimising clicks only | Use lead-quality and guardrail outcomes |
