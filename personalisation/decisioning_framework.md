# Decisioning Framework

## Inputs

- Journey stage
- Vehicle/model interest
- Configurator state
- Finance behaviour
- Dealer selection
- Returning status
- Consent and eligibility
- Experiment/personalisation collision rules

## Output

One approved next-best action, such as:

- Continue configuration
- Estimate repayment
- Select nearby dealer
- Book test drive
- View ownership content

## Rules

- Do not show multiple competing primary messages.
- Preserve a generic fallback.
- Avoid decisioning on sensitive information.
- Respect frequency and cooldown limits.
- Log experience exposure.
