# Personalisation Measurement

## Primary measures

- Qualified lead rate
- High-intent progression
- Configurator completion
- Test-drive booking
- CRM match rate

## Guardrails

- Page performance
- Exit rate
- Form errors
- Duplicate/invalid lead rate
- Consent changes
- Experience frequency
- Segment fairness review

## Analysis

Compare eligible personalised group with holdout using documented assignment and outcome windows. Include uncertainty and data-quality checks.
