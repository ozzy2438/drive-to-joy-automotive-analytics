# Audience Definitions

## AUD-HYB-001 — Hybrid Researchers

Eligibility:

- Viewed hybrid vehicle model or variant.
- Completed or repeated finance/ownership content interaction.
- Not already converted in cooldown window.

Experience: hybrid ownership-cost relevance and finance/configurator next step.

## AUD-CFG-002 — Configurator Abandoners

Eligibility: configurator started but not completed within defined session/window.

Experience: resume configuration or simplified next step.

## AUD-FIN-003 — Finance-Anxious Visitors

Eligibility: repeated finance calculator behaviour with no form submit.

Experience: repayment explanation and low-friction next action.

## AUD-RET-004 — Returning High Intent

Eligibility: returning user with multiple high-intent actions across defined period.

Experience: recently viewed vehicle, saved context and local dealer CTA.
